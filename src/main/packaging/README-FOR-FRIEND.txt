ANDROID REMOTE - HUONG DAN
==========================

1. Tren phone: bat Developer options va USB debugging.
2. Cam tat ca phone vao PC bang USB.
3. Bam dup START.cmd.
4. Tren phone, bam Allow neu hien cau hoi cho phep USB debugging.
5. Doi den khi cua so hien READY.
6. Link da duoc copy vao clipboard va luu trong file LINK.txt.
7. Gui link do cho nguoi can xem/dieu khien phone.

Khong dong cua so Android Remote khi dang chia se.
Nhan Ctrl+C de dung chia se. Link cu se ngung hoat dong.

LUU Y BAO MAT
-------------
Bat ky ai co link day du deu co the xem va dieu khien phone.
Chi gui link cho nguoi tin cay.

NEU KHONG THAY PHONE
--------------------
- Mo khoa man hinh phone.
- Kiem tra USB debugging da bat.
- Rut/cam lai cap USB.
- Chap nhan hop thoai Allow USB debugging tren phone.
- Voi mot so hang phone, Windows co the can USB driver cua hang.
